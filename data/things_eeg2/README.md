# THINGS-EEG2 Dataset

The THINGS-EEG2 dataset has **not** been downloaded yet.

## Download link

**OSF**: https://osf.io/3jk45

## About

THINGS-EEG2 is a large-scale EEG dataset containing neural responses to 22,248
images from the THINGS object concept database. It is commonly used for
EEG-based brain-image alignment research.

## How to download

Visit the OSF link above and download the files manually, or use the OSF CLI:

```bash
pip install osfclient
osf -p 3jk45 clone .
```

Place the downloaded files inside this directory (`data/things_eeg2/`).
